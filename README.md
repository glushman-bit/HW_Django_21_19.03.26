### Цель проекта научиться создавать простое веб приложение.

#### HTML файлы: 
 - page_catalog.html - страница с каталогами продукции
 - page_category.html - страница с категориями продукции
 - page_contacts.html - страница с контактами
 - page_main.html - главная страница

#### Класс MyServer 
 - простое веб-приложение - запускает локальный сервер, осуществляет GET и POST запросы.
